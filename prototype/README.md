# bookbookbook prototype

Open `index.html` directly from disk. The prototype is vanilla HTML/CSS/JS with classic script tags and stores changes in `localStorage`.

Mocked: AI responses, AI credits, sign-up, local/cloud speech engines, provider keys, snapshots, and template scaffolding. The browser Web Speech API is acknowledged; unavailable or denied speech falls back to a canned transcript. Read aloud uses `speechSynthesis` where available.

Shortcuts: `Ctrl/Cmd+K` command palette, `Ctrl+J` continue, `Ctrl+Shift+F` find, `Ctrl+.` focus mode, `Esc` close overlays. Use Settings → Privacy → Reset prototype data (click twice) to clear local state.
